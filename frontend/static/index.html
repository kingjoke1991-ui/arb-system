二、交易所凭据

      

        在此处填入交易所 API Key / Secret（OKX 还需 Passphrase）。保存后会立即写入服务器 .env 文件并热加载到当前进程——
        无需重启容器。已有值以脱敏形式显示；点击"显示"临时查看明文（5 秒后自动恢复）。
      

      

        ⚠️ 安全提示：保存后，密钥以明文形式存于 VPS 的 /opt/arb-system/.env。请确认：
        
① 此 VPS 的 SSH 仅你自己有访问；② 在交易所 API 设置中已勾选"仅限下单、禁止提币"，并绑定本 VPS 的 IP（34.84.8.21）；③ 如要更高安全性，建议用硬件钱包 / Vault / KMS 管理（当前 MVP 不支持）。
